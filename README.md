# «Карьерный маршрут: молодёжная сфера»
> Региональная цифровая платформа для специалистов по работе с молодёжью Ростовской области.
> Слоган проекта: **«Молодость. Карьера. Успех.»**

---

## 🌟 О проекте

Сайт представляет собой современный интерактивный карьерный навигатор и презентационную платформу сообщества специалистов Дона. Проект объединяет инфраструктуру 55 муниципальных образований Ростовской области (12 городских округов и 43 района), карту открытых пространств и молодёжных центров, вакансии, пошаговые ступени профессионального роста и реальные истории успеха коллег.

### Ключевые разделы платформы:
1. **Шапка сайта (`Header`)**: адаптивная навигация, переключение состояний при скролле, доступное мобильное меню.
2. **Главный экран (`HeroSection`)**: крупная акцидентная типографика (Unbounded), глубокий донской индиго `#062985`, подлинные векторные волны маркера и стрелки из презентации, фоторабота с лидером сферы, быстрые метрики.
3. **Бегущая строка (`Marquee`)**: непрерывный бесшовный тикер «Молодость. Карьера. Успех.», пауза при наведении, учёт `prefers-reduced-motion`.
4. **О проекте (`AboutSection`)**: асимметричная редакционная верстка, ценностные ориентиры («Инициатива», «Синергия», «Развитие»), фотоколлаж с реальными специалистами.
5. **Интерактивная карта Дона (`RegionalMapSection`)**: векторная карта Ростовской области с муниципалитетами, переключение между картой и списком (для мобильных), досье района с учреждениями, контактами и вакансиями.
6. **Основной карьерный маршрут (`CareerRoute`)**: 6 ступеней от волонтёра до регионального лидера с раскрывающимся досье (задачи, компетенции, образовательные платформы, переходы).
7. **Ключевые направления (`DirectionGrid`)**: модульная сетка треков (проекты и гранты, добровольчество, открытые пространства, медиа, патриотическое воспитание, карьера).
8. **Каталог профессий (`ProfessionCatalog`)**: живой поиск по ролям и навыкам, фильтрация по категориям, карточки с зарплатами и модальное окно с описанием задач.
9. **Навыки и развитие (`SkillsSection`)**: интерактивное сопоставление Soft Skills и Hard Skills с практическими советами по прокачке.
10. **Истории успеха (`SuccessStories`)**: портреты реальных специалистов из Ростова-на-Дону, Таганрога и Шахт, вехи карьеры и цитаты.
11. **Интерактивный тест выбора (`CareerSelector`)**: 3-шаговый навигатор с прогресс-баром и мгновенным расчетом подходящей роли и стартовой ступени.
12. **Экосистема возможностей (`OpportunitiesSection`)**: карточки программ Росмолодёжи, форума «Ростов», платформы Добро.рф и Академии.
13. **Часто задаваемые вопросы (`FAQSection`)**: доступный аккордеон с ответами на ключевые вопросы о старте и росте в ОРМ.
14. **Финальный призыв к действию (`FinalCTA`)**: высококонтрастный блок с фирменными графическими элементами.
15. **Подвал (`Footer`)**: полная навигация, официальные ресурсы, авторские права и кнопка возврата наверх.

## 🎨 Дизайн-система

- **Основной цвет**: Тёмно-синий `#062985` (глубокий индиго)
- **Акцентный цвет**: Кислотно-лаймовый `#C4E538`
- **Вспомогательные акценты**: Бирюзовый `#51C3DD`, Фиолетовый `#9B49DC`
- **Светлые фоны**: Нейтральный `#F4F6FB`, Светло-лаймовый `#F4FCDC`
- **Шрифты**:
  - Заголовки и акценты: **Unbounded** (Bold / ExtraBold / Black)
  - Основной текст: **Onest** (Regular / Medium / SemiBold)
  - Дисплейные цифры: **Oswald** (Condensed)
  - Рукописные ремарки: **Caveat** (Ink Free аналог с кириллицей)

## 🚀 Запуск и сборка

### Требования:
- Node.js 18+ (рекомендуется 20+)
- npm 9+

### Установка зависимостей:
```bash
npm install
```

### Запуск локального сервера разработки:
```bash
npm run dev
```

### Сборка production-версии:
```bash
npm run build
```
Статические оптимизированные файлы компилируются в папку `dist/`.

### Предпросмотр сборки:
```bash
npm run preview
```

## 📦 Архитектура и перенос в будущем

1. **Сейчас (GitHub Pages)**:
   - Полностью статическая сборка без необходимости в Node.js сервере на хостинге.
   - Относительные пути (`base: './'`), работающие в любых подкаталогах репозитория.
   - Готовый workflow автоматической сборки в `.github/workflows/deploy.yml`.

2. **В будущем (VPS + PostgreSQL + Node.js API)**:
   - Все сущности (`CareerStage`, `Direction`, `ProfessionRole`, `SkillItem`, `SuccessStory`, `MunicipalityItem`) строго типизированы в `src/types/index.ts`.
   - Данные централизованы в `src/data/`, интерфейс компонентов отвязан от прямого чтения файловой системы и обращается к типизированным коллекциям.
   - При переходе на бэкенд достаточно заменить слой чтения данных в `src/data/` на вызовы клиентского API без необходимости переделывать вёрстку или интерактивные компоненты.
